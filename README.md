## Uji awal Google Sheets

1. Buat Google Sheets dan isi teks pada kolom A, satu paragraf per baris.
2. Pilih **File → Bagikan → Publikasikan ke web**.
3. Pilih sheet yang digunakan dan format **CSV**, lalu publikasikan.
4. Salin URL publik CSV ke bagian **Uji Google Sheets** pada aplikasi KB.
5. Klik **Render halaman** untuk menampilkan hasilnya.

Pada tahap awal ini KB hanya membaca spreadsheet yang dipublikasikan secara publik. Setiap baris CSV yang berisi teks dirender sebagai paragraf. Data ditampilkan sebagai teks biasa, bukan HTML.
